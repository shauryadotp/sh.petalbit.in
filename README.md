# sh.petalbit.in

curl-pipe install wrappers.

```sh
curl -fsSL https://sh.petalbit.in/cli/<name> | bash
```

| script | installs |
| --- | --- |
| [agy](https://sh.petalbit.in/cli/agy) | Google Antigravity CLI |
| [bun](https://sh.petalbit.in/cli/bun) | Bun |
| [fnm](https://sh.petalbit.in/cli/fnm) | Fast Node Manager |
| [grok](https://sh.petalbit.in/cli/grok) | xAI Grok CLI |

each script pulls the official installer and pins PATH in `~/.bashrc`.
parent shells: `source ~/.bashrc`.
